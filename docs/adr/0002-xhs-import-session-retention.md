# 人工审核依赖视频链接与本地记录,不保留点点会话

2026-10-18 决定将本程序的已结束导入会话作为可清理的远端资源,包括待人工审核的会话。审核以视频原始链接和本地审核记录为依据,因此保留待审核对话只会累积历史会话;仍有未决请求或后续恢复依赖的会话暂不删除。清理只覆盖身份和访问账号归属可确认的本程序会话,本地请求、结果及审核记录继续保留。

这一选择牺牲已清理会话的远端历史可回看性,换取持续运行时会话数量可控。换会话后按条件清理,普通失败延后重试;用户已手工删除的会话在明确确认不存在后按完成处理,页面加载失败不能当作不存在。

具体运行窗口、清理规则和验证范围见[设计文档](../design/xhs-session-cleanup-and-schedule.md)。
